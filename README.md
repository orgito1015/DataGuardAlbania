## 🚀 Quick Start

### Option 1: GitHub Pages (Recommended)

1. Create a new GitHub repository named `dataguard-albania`
2. Upload all files from this folder
3. Go to **Settings** → **Pages**
4. Under "Source", select **Deploy from a branch**
5. Select branch: **main** and folder: **/ (root)**
6. Click **Save**
7. Your site will be live at: `https://YOUR-USERNAME.github.io/dataguard-albania/`

### Option 2: Local Development

```bash
# Simply open index.html in your browser
open index.html

# Or use Python's built-in server
python3 -m http.server 8000
# Then visit: http://localhost:8000
```

## 🔧 Customization

### Change Content

Edit `index.html` — all text is in Albanian and easy to find.

### Change Colors

Edit `css/style.css` — update CSS variables at the top:

```css
:root {
    --primary: #2563EB;
    --secondary: #06B6D4;
    --red: #E41E20;
    /* ... */
}
```

### Add Logo

1. Add your logo image to `/images/logo.png`
2. Edit `index.html` — replace the SVG logo with:

```html
<img src="images/logo.png" alt="DataGuard Albania" width="32" height="32">
```
